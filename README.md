# 🌱 EcoCred

### Blockchain-Based Token Reward System for Sustainable Behaviour

EcoCred is a blockchain-based platform that encourages people to adopt eco-friendly habits by rewarding verified sustainable activities with digital tokens.

Users can submit real-world activities such as tree planting, electricity saving, carpooling, water conservation, and waste management. Submitted activities are verified using OCR, GPS-based validation, and uploaded evidence before rewards are issued.

---

## ✨ Features

- 🌱 **Sustainable Activity Submission**  
  Users can upload proof of their eco-friendly activities.

- 🔍 **OCR Verification**  
  Extract and verify information from uploaded bills and documents using Gemini OCR.

- 📍 **GPS Validation**  
  Validate location-based sustainable activities using GPS and Google Maps API.

- 🪙 **Token Reward System**  
  Users receive tokens based on predefined thresholds for verified activities.

- 🔗 **Blockchain Records**  
  Transactions are securely recorded using blockchain technology for transparency and tamper resistance.

- 🛍️ **Reward Marketplace**  
  Users can redeem tokens for discounts on eco-friendly products.

- 👨‍💼 **Admin Panel**  
  Administrators can manage users, activities, products, transactions, and verification.
